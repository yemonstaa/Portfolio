02 / Case studies

Behind the build.

Goals, key decisions, and the features built to solve each problem.

ChickenRunnerPOS Offline-first point of sale · Electron, React, TypeScript

Goal: Keep a single-store checkout dependable even without internet.

Built: A local-first register with cashier/admin roles, barcode scanning, held orders, cash and GCash payments, inventory controls, and ESC/POS receipt printing.

Operations: Low-stock alerts, protected voids/refunds, CSV import/export, sales reports, and local backups.

Sign-in & local use: The screen reports offline status and the local database, with a demo option for a quick walkthrough.

MFDungeons Party dungeon plugin · Java, Paper, MythicMobs

Goal: Make repeatable party dungeons configurable without hand-building every run.

Built: Isolated dungeon instances, GUI setup, custom mob waves and MythicMobs bosses, plus progression triggers for clears, keys, mechanisms, and timed area holds.

Player flow: Timed BossBars, configurable rewards, and automatic instance cleanup.

MineFront Minecraft network operations · Dedicated server, Pterodactyl

Goal: Build a stable home for Skyblock, Lifesteal, and Survival.

Built: Operations on a Ryzen 9 9950X host with 32 GB RAM, Pterodactyl-managed instances, and JVM/startup tuning by mode.

Status: In development.

DonkeyVerifier Discord member verification · JavaScript, Discord.js

Goal: Give community members a quick, clear verification flow.

Built: A one-click panel that checks for an existing verified role, assigns it when needed, and returns private feedback if the role is missing.

DonkeyLogger Discord moderation audit trail · JavaScript, Discord.js

Goal: Give moderators a useful record of activity and server changes.

Built: Event logging for messages, channel creation, edits/deletions, role changes, and voice moves, with audit-log lookups to identify supported actions.

MFMachines Chunk machines and collection plugin · Java, Paper

Goal: Automate resource collection while keeping each machine's storage and power limits meaningful.

Built: Filtered, tiered Infinity Chests; battery-powered radius Collectors with limited buffers; and Chunk Loaders.

Operations: Linking and trust controls, configurable machine GUIs, SQLite-backed machine state, and optional Vault selling integration.

MFResources Developer marketplace and customer portal · Next.js, TypeScript

Goal: Present developer products and custom commissions in one organized storefront.

Built: Marketplace browsing and resource details, commission/contact pages, customer dashboard views, and an admin preview.

Status: Frontend currently uses mock data. Authentication, checkout, downloads, licensing, and persistent workflows remain planned.

Finch Finance Dashboard Local-first budgeting helper · HTML, CSS, JavaScript

Goal: Make everyday budgeting usable on a phone while keeping the ledger in the user's browser.

Built: Transaction and bill tracking, expected-income handling, spending summaries, and purchase-planning guidance.

Privacy: Data stays in local browser storage and can be backed up or restored. The public portfolio does not link to a demo or expose financial entries.
